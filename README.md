# M2 Systems (Create React App + TypeScript)

This repository now contains a Create React App (TypeScript) sample with routing using react-router-dom v6. It provides a vertical sidebar with three routes:

- / -> Home (title: "M2 Systems")
- /business -> Business Overview
- /contact -> Contact Us

How to run locally:

1. Ensure Node.js (>=16) and npm are installed.
2. From the repo root:
   - npm install
   - npm start
3. Open http://localhost:3000

Notes:
- The project uses TypeScript and functional React components.
- The contact form is simulated client-side only.
